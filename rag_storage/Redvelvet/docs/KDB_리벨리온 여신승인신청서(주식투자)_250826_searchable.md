[참고] AI 반도체의 구분과 핵심기능
학습(Training) vs 추론(Inference)
학습은 대규모 데이터를 기반으로 AI 알고리즘을 거쳐 지식을 습득(AI 모델 구현)하는 단계이며,
추론은 학습한 내용을 토대로 외부 명령 등에 대한 결과를 도출하는 단계임
처리량(Throughput) vs 응답속도(Latency)
•처리량은 일정시간 동안 처리하는 작업의 양을 의미하며, 응답속도는 요청을 처리하고 응답할 때까지
걸리는 시간(ChatGPT에게 질문시 답변 표출까지의 시간)을 의미
모델 구축 단계에서는 신속한 구축을 위해 수많은 연산을 수행해야 하므로 처리량이 중요한 반면,
서비스 단계에서는 서비스 퀄리티 차원에서 빠른 응답 속도가 중요함
