노앤파트너스주식회사 귀하
삼정회계법인(이하“삼정KPMG”)은노앤파트너스주식회사(이하“귀사” 또는
“회사”)와체결한용역계약에따라, 귀사가검토하고있는신주인수관련내부의
사결정지원목적으로2025년12월31일(이하“평가기준일”) 기준리벨리온주
식회사(이하“대상회사“)의인수가격분석용역(이하“본용역”)을수행하고그결
과를다음과같이보고서를통해제출하는바입니다. 
본용역결과물에포함되어있는정보는보고서제출일이전까지회사및대상회
사로부터제공받은자료를바탕으로작성된것이며, 삼정KPMG는보고서일이후
발생된사건이나변경된내용에대하여본보고서를갱신하거나수정할의무를부
담하지아니합니다.
본보고서는계약서상에명시된목적이외로사용될수없습니다. 또한, 어떠한
방식으로도본보고서를귀사의감사인외제3자에게공개할수없으며, 제3자에
의하여사용되지않도록해야합니다. 
보고서이용에관한고지:
삼정KPMG는본보고서를작성하기위하여대상회사가제시한대상회사의사업계획에
대한검토를실시하였으며, 이러한검토결과에기초하여인수가격분석을수행하였습니
다. 본보고서에포함되어있는분석대상에대한각종정보의작성책임은대상회사에있
으며삼정KPMG는대상회사가제시한정보에근거하여동정보의정확성에대한추가적
인검증절차없이용역업무를수행하였습니다. 삼정KPMG는대상회사가제시한재무
정보에대하여추세분석, 특성검토및논리적인검토를수행하였으며, 필요하다고판단
되는경우담당자면담등의적절한방법을사용하였습니다.
본보고서에포함되어있는미래기간에대한추정재무정보에는분석대상의향후사업계
획및현금흐름에대한일정한가정이포함되어있으며, 우발채무의발생, 향후거시경제
지표의변동등예기치못한제반요소및계량화되지못한위험요인들에의하여영향을
받을수도있으므로장래의실적결과와일치하지않을수있습니다. 또한서비스이관후
귀사와양수자간거래및적정요율에대해서는귀사로부터제공받은거래내용과요율을
적용하여분석하였으며, 실제계약및거래내용이이와달라질경우분석내용이달라질
수있습니다. 따라서삼정KPMG는분석대상의미래재무정보의추정치에대하여어떠
한확신을표명하거나보장을하지않으며, 또한본보고서상에제시된분석금액이분석
대상의절대적가치나시장가치를보증하는것은아니므로, 본보고서의이용자는의사결
정에있어평가에적용된방법과한계를충분히고려하여야합니다.
본보고서의이용자는의사결정에있어본보고서를의사결정의유일한근거나참고로활
용하여서는아니되며, 삼정KPMG는이로인하여발생되는손해또는손실에대하여어
떠한책임도부담하지아니합니다. 또한삼정KPMG 및삼정KPMG의관계회사, 삼정
KPMG의임직원은본보고서와관련하여어떠한보증이나보장도제공하지아니하며모
든의사결정은의사결정자의판단과책임하에이루어져야합니다.
삼정KPMG는용역계약서에서별도로규정하지않는한, 본보고서제출이후에발생하
는사건에대하여본보고서를갱신할의무를부담하지않습니다.
본보고서는초안으로최종보고서가아닙니다. 본보고서초안에언급된내용중일부는수
정되거나삭제될수있습니다.
