# Noh & Partners IM — 스타일시트 & 레이아웃 프롬프트

> Project Redvelvet IM v10 (59 slides, 2026.03) 실측 분석 기반
> 설계 원칙: **본문 슬라이드 + 파트 구분 슬라이드, 이 2가지만 잘 만든다.**

---

## 핵심 설계 원칙

일관성을 유지하는 요소는 **세 가지**뿐이다:

| # | 요소 | 결정사항 |
|---|------|---------|
| 1 | **폰트** | 맑은 고딕 Bold + Regular (영문 혼용 안정적). pptxgenjs에서는 `fontFace: 'Arial'`로 지정 후 한글은 자동 fallback |
| 2 | **컬러** | Navy(#0C3064) 중심 6색 팔레트. 아래 §1 참조 |
| 3 | **레이아웃 구조** | 5개 존(Zone) 기반 본문 슬라이드. 아래 §3 참조 |

**슬라이드는 2종류만 설계한다:**
- **본문 슬라이드** — 모든 컨텐츠가 담기는 표준 서식
- **파트 구분 슬라이드** — 메인 컬러 배경 + 화이트 텍스트

표지와 목차는 각각 1장이므로 서식 템플릿이 필요 없다. 본문과 파트 구분, 이 두 개만 잘 만들면 전체가 일관된다.

## §1. 컬러 팔레트

슬라이드 마스터에 명시된 6색 브랜드 컬러:

| 역할 | 이름 | Hex | RGB | 사용처 |
|------|------|------|------|--------|
| **메인** | Navy | `#0C3064` | 12,48,100 | 테이블 헤더, 서브섹션 바, 파트 구분 배경, 섹션 탭 |
| 보조1 | Blue | `#005DA2` | 0,93,162 | 차트 2nd series, 보조 강조 |
| 보조2 | Sky Blue | `#00A2E8` | 0,162,232 | 차트 3rd series, 아이콘 |
| **액센트** | Gold | `#CCA000` | 204,160,0 | 서브섹션 바 좌측 스트라이프, 하이라이트 셀, 배지 |
| **강조** | Red | `#C00000` | 192,0,0 | 핵심 수치(금액·%·KPI), 경고 |
| **본문** | Dark Grey | `#404040` | 64,64,64 | 일반 본문 텍스트 (순수 검정 #000000은 미사용) |

보조 컬러 (실측 추가):

| Hex | 용도 |
|------|------|
| `#001D3D` | 슬라이드 제목 텍스트 (Deep Navy) |
| `#F2F2F2` | 테이블 교차행, 박스 배경 (Light Grey) |
| `#64748B` | 각주, 소스, 캡션 (Muted Slate) |
| `#BFBFBF` | 테이블 테두리, 구분선 |
| `#FFFFFF` | 슬라이드 배경, 테이블 셀, 파트 구분 텍스트 |

**컬러 비중: White(60%) → Navy+Grey(30%) → Gold+Red(10%)**

## §2. 폰트 & 타이포그래피

### 서체

```
fontFace: 'Arial'          // pptxgenjs 지정값
한글 fallback: 맑은 고딕    // OS 자동 적용
```

맑은 고딕은 Bold와 Regular을 함께 써도 가독성이 자연스럽고, 영문·한글 혼용 슬라이드에서 안정적이다. pptxgenjs에서는 `Arial`로 지정하되, 한글이 포함되면 시스템이 맑은 고딕으로 자동 렌더링한다.

### 크기 체계

본문 슬라이드에서 사용되는 텍스트 크기는 **4단계**로 제한한다:

| 단계 | 크기 | 굵기 | 용도 |
|------|------|------|------|
| **L** | 24pt | Bold | 슬라이드 타이틀 |
| **M** | 11pt | Bold | 헤더/거버닝 문구, 서브섹션 바 텍스트, 소제목 |
| **S** | 11pt | Regular | 본문, 테이블 셀, 불릿 텍스트 |
| **XS** | 9pt | Regular | 섹션 탭, 각주, 소스, 페이지 번호 |

> 크기를 더 세분화하지 않는다. 11pt Bold vs 11pt Regular의 차이만으로 계층을 구분한다.

## §3. 본문 슬라이드 (Content Slide)

**이것이 전체 IM의 95%를 차지하는 핵심 서식이다.**

### 존(Zone) 맵

```
┌─────────────────────────────────────────────────────┐
│ ZONE A: 타이틀 영역                    ZONE B: 섹션 탭│
│ ┌──────────────────────────────────┐  ┌────────────┐│
│ │ 슬라이드 제목 (24pt Bold)        │  │ III. 시장분석││
│ │ 서브타이틀 (보조 설명)           │  │  (9pt Navy) ││
│ └──────────────────────────────────┘  └────────────┘│
│ ZONE C: 헤더/거버닝 문구 (핵심 메시지 강조)          │
│ ┌───────────────────────────────────────────────────┐│
│ │ 11pt Bold, 1~2줄. 이 슬라이드의 핵심 결론을 요약  ││
│ └───────────────────────────────────────────────────┘│
│                                                      │
│ ZONE D: 본문 영역 (자유 편집 공간)                   │
│ ┌───────────────────────────────────────────────────┐│
│ │                                                   ││
│ │  서브섹션 바 + 테이블/차트/텍스트/다이어그램       ││
│ │  (1열 전체 또는 2열 분할)                          ││
│ │                                                   ││
│ └───────────────────────────────────────────────────┘│
│ ZONE E: 푸터 (소스 / 페이지번호 / 기밀표시)          │
└─────────────────────────────────────────────────────┘
```

### 존별 실측 좌표 & 스타일

#### ZONE A — 타이틀 (슬라이드 제목 + 서브타이틀)

| 요소 | x | y | w | h | 스타일 |
|------|---|---|---|---|--------|
| 슬라이드 제목 | 0.42" | 0.54" | 9.37" | 0.53" | 24pt Bold `#001D3D` |
| 서브타이틀 | — | — | — | — | 제목 바로 아래, 12pt Regular `#404040` (필요시) |

#### ZONE B — 섹션 탭 (상단 파트 구분 표시)

| 요소 | x | y | w | h | 스타일 |
|------|---|---|---|---|--------|
| 섹션 레이블 | 0.40" | 0.24" | 9.39" | 0.30" | 9pt Regular `#0C3064` |

> "I. Executive Summary", "II. 대상회사 분석" 등 현재 어떤 파트인지 표시한다. 모든 본문 슬라이드 최상단에 동일하게 반복된다.

#### ZONE C — 헤더/거버닝 문구 (핵심 메시지 강조)

| 요소 | x | y | w | h | 스타일 |
|------|---|---|---|---|--------|
| 거버닝 문구 | 0.41" | 1.33" | 11.09" | 0.53" | 11pt Bold `#000000` |

> **이 슬라이드의 핵심 결론을 1~2줄로 요약한 문장이다.** 예: "Entry Value 2.45조원은 Forward EV/Sales 4.3x로, 글로벌 경쟁사 평균 9.5x 대비 합리적인 수준임"

#### ZONE D — 본문 영역 (자유 편집 공간)

| 속성 | 값 |
|------|------|
| 시작 y | 2.05" (서브섹션 바 포함 시) 또는 2.00" (바 없이) |
| 끝 y | 7.55" (소스 라인 직전) |
| 사용 가능 높이 | 약 **5.5"** |
| 좌측 x | 0.41" |
| 우측 끝 | 11.50" |
| 사용 가능 너비 | 약 **11.09"** |

본문 영역의 **레이아웃 변형**:

| 변형 | 설명 | 서브섹션 바 |
|------|------|------------|
| **1열 전체** | w=11.09" 단일 패널 (대형 테이블, 타임라인) | 1개 (full-width) |
| **2열 균등** | 좌=0.41" w=5.35", 우=6.16" w=5.35" (가장 빈번) | 2개 (좌/우 각 1개) |
| **2열 비대칭** | 좌 넓음 + 우 좁음 또는 그 반대 | 1~2개 |
| **넘버링 블록** | 01~05 세로 배치 (Investment Highlight 등) | 없음 (직접 구분) |

#### ZONE E — 푸터

| 요소 | x | y | w | 스타일 |
|------|---|---|---|--------|
| Source / Note | 0.42" | 7.88" | 9.68" | 9pt Regular `#64748B` |
| 페이지 번호 | 5.75" | 8.15" | 0.43" | 9pt Regular `#404040`, center |
| 기밀표시 | 9.32" | 8.23" | 2.19" | 8pt Regular `#404040`, right |

> 기밀표시: "Strictly Private and Confidential" — **모든 본문 슬라이드에 필수**.

---

### 서브섹션 바 (Zone D 내부의 핵심 반복 패턴)

본문 영역 최상단에 위치하는 컨텐츠 패널 헤더. 거의 모든 본문 슬라이드에 1~2개 등장한다.

```
┌─────────────────────────────────────┐
│██│         서브섹션 제목             │
│Gold        Navy (#0C3064) 배경      │
│0.08"       White 11pt Bold          │
└─────────────────────────────────────┘
 ↑                                    ↑
 w=0.08"              전체 w=5.35"
```

| 속성 | 값 |
|------|------|
| 전체 너비 | **5.35"** (고정 — 1열이든 2열이든 동일) |
| 높이 | 0.32" |
| y 좌표 | 2.05" |
| x (1열일 때) | 0.41" |
| x (2열 좌측) | 0.41" |
| x (2열 우측) | 6.16" |
| Gold 스트라이프 | 좌측 0.08" 너비, `#CCA000` |
| Navy 본체 | `#0C3064` |
| 텍스트 | 11pt Bold White, left-padding 0.15" |

```javascript
// pptxgenjs 서브섹션 바 헬퍼
function addSubSectionBar(slide, title, x, y) {
  slide.addShape('rect', {
    x, y, w: 0.08, h: 0.32,
    fill: { color: 'CCA000' }, line: { type: 'none' }
  });
  slide.addShape('rect', {
    x: x + 0.08, y, w: 5.27, h: 0.32,
    fill: { color: '0C3064' }, line: { type: 'none' }
  });
  slide.addText(title, {
    x: x + 0.15, y, w: 5.20, h: 0.32,
    fontSize: 11, fontFace: 'Arial', bold: true,
    color: 'FFFFFF', valign: 'middle'
  });
}
```

## §4. 파트 구분 슬라이드 (Section Divider)

**메인 컬러를 배경으로 채우고 텍스트를 화이트로 변경한다.** 이것이 전부다.

실측에서는 좌측에 Gold+Navy 대각선 장식이 있지만, AI 생성 시에는 심플한 단색 배경이 더 안정적이다.

### 실측 좌표

```
┌─────────────────────────────────────────────────┐
│                                                  │
│  ┌─ 대각선 장식 ─┐                               │
│  │  Gold + Navy  │     ─── (short navy 0.79"W)   │
│  │  밴드 + 도트  │     ─── (long grey 5.72"W)    │
│  │  패턴 오버레이│                                │
│  │               │     II. 대상회사 분석          │
│  │               │     (36-44pt Bold White)       │
│  │               │                                │
│  └───────────────┘                                │
│                                [N] NOH & PARTNERS │
└─────────────────────────────────────────────────┘
```

| 요소 | x | y | w | h | 스타일 |
|------|---|---|---|---|--------|
| 섹션 제목 | 6.17" | 2.17" | 5.66" | 0.74" | 36-44pt Bold `#001D3D` (실측) 또는 White (단색 배경 시) |
| Short line | 6.17" | 1.86" | 0.79" | — | 2pt `#0C3064` Navy |
| Long line | 6.21" | 1.86" | 5.72" | — | 1pt Grey |

### AI 생성용 단순화 버전

대각선 장식 없이 메인 컬러 배경만 사용하는 경우:

```javascript
function addSectionDivider(pptx, title) {
  const slide = pptx.addSlide();
  // Navy 전체 배경
  slide.addShape('rect', {
    x: 0, y: 0, w: 11.93, h: 8.50,
    fill: { color: '0C3064' }, line: { type: 'none' }
  });
  // 섹션 제목 (중앙)
  slide.addText(title, {
    x: 1.0, y: 3.0, w: 9.93, h: 2.0,
    fontSize: 40, fontFace: 'Arial', bold: true,
    color: 'FFFFFF', align: 'center', valign: 'middle'
  });
  return slide;
}
```

원본 스타일을 충실히 재현하려면 좌측 대각선 + 도트 패턴이 필요하지만, 이는 이미지 에셋을 슬라이드 마스터에 포함시키는 방식으로 처리하는 것이 현실적이다.

## §5. 본문 슬라이드 생성 — 통합 템플릿

```javascript
// ─── 슬라이드 기본 설정 ───
const pptx = new PptxGenJS();
pptx.defineLayout({ name: 'NP_IM', width: 11.93, height: 8.50 });
pptx.layout = 'NP_IM';

// ─── 푸터 헬퍼 ───
function addFooter(slide, source, pageNum) {
  if (source) {
    slide.addText(source, {
      x: 0.42, y: 7.88, w: 9.68, h: 0.31,
      fontSize: 9, fontFace: 'Arial', color: '64748B'
    });
  }
  slide.addText(String(pageNum), {
    x: 5.75, y: 8.15, w: 0.43, h: 0.32,
    fontSize: 9, fontFace: 'Arial', color: '404040', align: 'center'
  });
  slide.addText('Strictly Private and Confidential', {
    x: 9.32, y: 8.23, w: 2.19, h: 0.15,
    fontSize: 8, fontFace: 'Arial', color: '404040', align: 'right'
  });
}

// ─── 본문 슬라이드 생성 ───
function createContentSlide(pptx, {
  sectionLabel,   // ZONE B: "I. Executive Summary"
  slideTitle,     // ZONE A: "Deal Structure"
  governing,      // ZONE C: 핵심 메시지 1~2줄 (선택)
  subSections,    // ZONE D: [{title, x}] 서브섹션 바 목록
  source,         // ZONE E: "Source: Company Information, NP Analysis"
  pageNum         // ZONE E: 슬라이드 번호
}) {
  const slide = pptx.addSlide();

  // ZONE B — 섹션 탭
  slide.addText(sectionLabel, {
    x: 0.40, y: 0.24, w: 9.39, h: 0.30,
    fontSize: 9, fontFace: 'Arial', color: '0C3064'
  });

  // ZONE A — 타이틀
  slide.addText(slideTitle, {
    x: 0.42, y: 0.54, w: 9.37, h: 0.53,
    fontSize: 24, fontFace: 'Arial', bold: true, color: '001D3D'
  });

  // ZONE C — 거버닝 문구
  if (governing) {
    slide.addText(governing, {
      x: 0.41, y: 1.33, w: 11.09, h: 0.53,
      fontSize: 11, fontFace: 'Arial', bold: true, color: '000000'
    });
  }

  // ZONE D — 서브섹션 바(들)
  if (subSections) {
    subSections.forEach(sub => {
      addSubSectionBar(slide, sub.title, sub.x || 0.41, 2.05);
    });
  }

  // ZONE E — 푸터
  addFooter(slide, source, pageNum);

  return slide;
  // ZONE D의 나머지 본문(표/차트/텍스트)은 return된 slide에 추가한다
}
```

## §6. 테이블 스타일

### 기본 테이블 규칙

| 속성 | 값 |
|------|------|
| 헤더 행 배경 | `#0C3064` Navy |
| 헤더 텍스트 | 11pt Bold White, center |
| 본문 행 배경 | 교차: `#FFFFFF` / `#F2F2F2` |
| 본문 텍스트 | 11pt Regular `#404040` |
| 숫자 정렬 | right 또는 center |
| 텍스트 정렬 | center (가장 빈번) 또는 left |
| 소계/합계 행 | Bold, 상단 경계선 강조 |
| 하이라이트 행 | `#CCA000` Gold 배경 또는 `#C00000` Red 텍스트 |
| 셀 패딩 | 상하 0.04", 좌우 0.08" |
| 테두리 | `#BFBFBF` 1px 또는 없음 |
| 전체 너비 | 5.22" (2열 패널) 또는 11.09" (full-width) |

### 재무제표 테이블 특수 규칙

- 연도 헤더: "2025A" (실적), "2026F" (추정), "2027E" (예상) 등으로 구분
- 음수: 괄호 표기 `(29,667)` — 빨간색 미사용
- 단위: 좌상단 셀에 "백만원", "단위: 억원" 등 기재

## §10. 실측 레퍼런스 — 컨텐츠 유형별 본문 영역 활용

> 아래는 Zone D(본문 영역) 내부를 어떻게 채우는지에 대한 가이드.
> 존 구조(A~E)는 모든 슬라이드에서 동일하며, 바뀌는 것은 Zone D 내부뿐이다.

### Deal Structure / 주주구성
- **2열 균등**: 좌측 투자구조 다이어그램 + 우측 주주구성 테이블
- 투자자 블록 → 대상회사 블록으로 꺾임선(elbow) 연결
- "당 펀드" 행은 Gold 배경 Bold로 하이라이트

### Term Sheet
- **1열 전체**: Full-width 3열 테이블 (구분 | 세부 | 내용)
- 내용 열은 불릿(•) 리스트로 각 조건 나열

### Funding History
- **1열 전체**: 라운드별 열(Seed~본건), 행(시기/금액/밸류/투자자/이벤트)
- 마지막 열("본건 투자")만 Gold 배경 하이라이트

### 제품/기술 비교
- 비교 매트릭스 테이블 (제품별 열, 속성별 행)
- 커스텀 수평 바로 성능 비교 시각화
- 하단에 고객사 로고/사례 배치

### 시장 분석
- **2열 균등**: 좌측 차트(COLUMN) + 우측 트렌드 설명
- 넘버링 배지(원형, Navy 배경 + White 숫자) + 소제목 Bold + 설명 Regular

### 재무제표
- **1열 전체** 또는 **2열**: Full-width 재무 테이블 + 하단 Commentary
- IS, BS, CF 각각 별도 슬라이드

### Valuation / Exit
- **2열 균등**: 좌측 Entry Value 산출 + 우측 유사기업 사례
- 하단에 Investment Merit 넘버링 블록

### Investment Highlight
- **넘버링 블록** (01~05): 서브섹션 바 없이 직접 구분
- 넘버 배지 + 소제목(Bold) + 불릿 본문(Regular)
- 교차 Grey 밴드로 시각적 구분
